# ADG PAY 官网优化方案

> 基于《支付行业官网设计分析报告》（docs/payment-websites-design-analysis.md）的竞品洞察制定
> 制定时间：2026-09-25
> 状态：待评审，**暂不执行重构**

---

## 一、现状诊断

### 1.1 当前项目概况

ADG PAY 官网为 Vue 3 + Vite 单页应用，中英双语（data-attribute 方案），包含页面：

- 首页 HomeView（Hero + 核心产品 + 行业方案 + 双语支持 + 为什么选择我们 + 牌照展示 + 四步流程 + CTA）
- 产品 ProductsView、关于 AboutView、合规 ComplianceView、FAQ、联系 ContactView、隐私 PrivacyView
- 组件：AppHeader、AppFooter、HeroGlobe（地球动效）、ChatAssistant

### 1.2 与竞品对比的主要差距

| 维度 | ADG PAY 现状 | 竞品最佳实践 | 差距 |
|------|-------------|-------------|------|
| Hero 视觉 | 地球动效 + 文字 | Mastercard/Tenpay 全屏场景图 + 强文案 | Hero 文案层级弱，缺少奖项/数据前置背书 |
| 数据背书 | 4 个 stat 为纯文字标签，无数字 | Airwallex 大数字滚动、Tenpay「20年/10亿+/200+」 | **缺少可量化的数字信任状** |
| 产品展示 | 4 张静态卡片 | Airwallex Tab 切换 + 手风琴、Tenpay 场景入口卡 | 卡片无视觉层次，缺产品界面截图/演示 |
| 信任背书 | 仅牌照展示 | Tenpay 合作伙伴 Logo 墙、客户证言轮播 | **缺少客户证言、合作伙伴 Logo 墙** |
| 滚动动画 | 基础交互 | 竞品全部标配 fade-in/slide-up/count-up/stagger | 动画体系不完整 |
| CTA 布局 | Hero 双 CTA + 页尾 CTA | Mastercard 固定底部 CTA 条、Airwallex 多处入口 | 转化触点密度不足 |
| 导航 | 常规顶部导航 | 竞品均为固定导航 + 滚动收缩 + 常驻转化按钮 | 导航缺常驻 CTA |
| 内容节奏 | 同质卡片区块连续 | 竞品通过深浅背景交替、图文交错保持兴趣 | 视觉节奏单调 |

### 1.3 品牌定位建议

参照竞品定位光谱（厚重权威 ↔ 科技产品 ↔ 极简功能 ↔ 生态体验 ↔ 亲和本地），ADG PAY 的差异化要素是：**香港 MSO 持牌 + 中文本地化服务 + 中小跨境企业用得起**。

建议定位：**「亲和本地型」为底色，叠加「科技产品型」的可信数据表达**——即 BBMSL 的亲和力 + Airwallex 的数据感。

## 二、优化目标

1. **提升信任转化**：用数字、证言、Logo 墙补齐信任链
2. **提升视觉质感**：统一动画体系、优化视觉节奏
3. **提升转化效率**：增加 CTA 触点、优化导航常驻转化入口
4. **保持技术栈**：Vue 3 + Vite 不变，沿用现有双语方案与路由结构

## 三、首页重构方案（Section 级）

### 3.1 Hero 区优化

**现状问题**：地球动效吸睛但文案层级弱；4 个 stat 是文字标签而非数据；无背书前置。

**优化措施**：

- 标题层级：主标语加粗加大（参照 Tenpay「支付无界 连接无限」的双行大标题节奏），副标题精简至一句话
- **stat 区数字化改造**：将 4 个文字标签升级为可量化指标（需业务方确认真实数据），例如：
  - 支持币种数量（如「15+ 币种账户」）
  - 服务企业数量（如「2,000+ 跨境企业」）
  - 到账时效（如「T+0 最快到账」）
  - 持牌年限或合规记录（如「MSO 持牌机构」）
- 数字应用 **count-up 滚动动画**（参照 Airwallex/Tenpay）
- Hero 下方增加**奖项/资质条**（参照 Tenpay 首屏奖项前置）：MSO 牌照徽标 + 合作银行/机构 Logo 简版横排
- 保留 HeroGlobe 地球动效，但降低视觉权重（降低不透明度或缩小），让位于文案与数据

### 3.2 核心产品区优化

**现状问题**：4 张卡片纯图标+文字，无层次无重点。

**优化措施**（二选一）：

- **方案 A（推荐，改动小）**：卡片升级——每张卡增加产品界面缩略图或示意插画（参照 Adyen 绿色系扁平插画的统一风格），hover 上浮 + 阴影加深 + 描边高亮（参照 Airwallex）
- **方案 B（改动大，效果更好）**：改为 **Tab 切换 + 手风琴功能列表**（参照 Airwallex「一站式平台」区），左侧 Tab 列表，右侧产品界面截图 + 功能点 + CTA

### 3.3 行业解决方案区优化

**现状问题**：3 张行业卡片样式与核心产品区雷同，视觉疲劳。

**优化措施**：

- 改为**场景化入口卡**（参照 Tenpay 蓝色横幅 + 白色场景卡）：深蓝/深色背景区块 + 白色场景卡片，与前后浅色区块形成节奏对比
- 每张行业卡增加代表性场景意象（电商/贸易/SaaS 的差异化图形）
- hover 效果：上浮 + 箭头动效（参照 Tenpay 场景卡的箭头引导）

### 3.4 新增：客户证言区

**现状**：缺失。

**优化措施**（参照 Airwallex 证言轮播）：

- 在行业方案区之后新增**客户证言轮播**：客户引言 + 行业标签 + 匿名化处理（如「某跨境电商头部卖家」）
- 2-3 条证言自动轮播 + 手动切换圆点
- 若无真实证言，可先用典型使用场景描述代替，避免虚构具体客户名

### 3.5 新增：合作伙伴 Logo 墙

**现状**：缺失。

**优化措施**（参照 Tenpay Logo 滚动墙）：

- 新增**合作机构 Logo 墙**：合作银行、支付网络、平台伙伴 Logo 横向自动滚动
- Logo 统一灰度处理，hover 恢复彩色
- 若无足够合作方，可与「牌照展示」区合并，在牌照卡旁列合作机构

### 3.6 牌照展示区优化

**现状**：信息正确但视觉平淡。

**优化措施**：

- 改为深色背景区块（参照 Airwallex 深色区块与 Mastercard 深色卡），形成视觉锚点
- 牌照卡片增加质感（渐变描边、微阴影），kv 列表排版优化为两列
- 右侧可放置合规要点图标列（反洗钱、资金隔离、尽职审查）

### 3.7 四步流程区优化

**优化措施**：

- 步骤之间增加**连接线/箭头**引导视线（参照竞品流程区常见做法）
- 步骤数字加大并应用品牌色
- 滚动进入时 stagger 依次出现

### 3.8 CTA 区优化

**优化措施**：

- 页尾 CTA band 保留，文案聚焦行动（「免费咨询开户」为主按钮）
- **新增固定底部 CTA 条**（参照 Mastercard，可选）：用户滚过 Hero 后出现的吸底条「免费咨询开户 + 查看产品」，可关闭，移动端隐藏以避免遮挡
- 导航栏右侧常驻「免费开户」主按钮（参照 Airwallex/Adyen 导航 CTA）

## 四、全局优化项

### 4.1 动画体系统一

建立全站统一的动效规范（写入样式体系）：

| 动效 | 参数 | 应用场景 |
|------|------|---------|
| fade-in-up | translateY(24px) → 0，opacity 0 → 1，600ms ease-out | 区块标题、卡片 |
| stagger | 每卡片延迟 80-120ms | 卡片网格 |
| count-up | 1200ms，进入视口触发一次 | 数据指标 |
| 卡片 hover | translateY(-4px) + 阴影加深 + 描边高亮，200ms | 所有卡片 |
| 按钮 hover | 颜色加深/反色，150ms | 所有按钮 |

实现方式：基于 IntersectionObserver 封装 `useScrollReveal` composable（可扩展现有 useInteractions.js），避免引入重型动画库。

### 4.2 视觉节奏

深浅背景交替，避免连续同质感区块。建议首页节奏：

```
Hero（深/地球） → 数据条（白） → 核心产品（浅灰） → 行业方案（深蓝） → 证言（白） → 牌照（深） → 流程（浅灰） → CTA（品牌色）
```

### 4.3 导航栏

- 滚动时收缩 + 背景由透明变白色带阴影（参照 Airwallex/BBMSL）
- 右侧常驻「免费咨询开户」主按钮
- 保持中英双语切换入口位置不变

### 4.4 配色与字体

- 维持现有品牌色不变，重点检查**品牌色在深色/浅色背景上的对比度合规**（WCAG AA）
- 标题字重与字号层级参照竞品：Hero 大标题 ≥ 48px（桌面端），区块标题 32-36px，卡片标题 20px
- 中文排版行高 1.6-1.7，数字与英文使用 tabular-nums 保证数据区对齐

### 4.5 响应式

- 卡片网格：桌面 4 列 → 平板 2 列 → 移动 1 列
- 固定底部 CTA 条移动端隐藏或改为悬浮按钮
- Logo 墙滚动在移动端降速

### 4.6 双语一致性

- 新增区块的所有文案需同步维护 `data-en` / `data-zh` 属性
- 英文版注意大标题换行控制（现有方案用 `<br/>` 控制，新增内容沿用）
